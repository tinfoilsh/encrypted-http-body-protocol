# Security Policy

Report a suspected vulnerability by email to [security@tinfoil.sh](mailto:security@tinfoil.sh). Please do not open a public issue or pull request for it.

We aim to respond within 24 hours. Fixed vulnerabilities are published as [security advisories](https://github.com/tinfoilsh/encrypted-http-body-protocol/security/advisories) on this repository.

What the protocol does and does not protect is stated in [SPEC.md, Section 7](SPEC.md#7-security-considerations).
